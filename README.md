# 🐻 샌드베어 (언양) 카페 사이트

설치할 라이브러리 없이 파이썬만으로 돌아가요. 데이터는 `data/sandbear.db` 파일 하나에 저장돼요 (GitHub 에는 안 올라감).

## 화면 4개

| 주소 | 누가 | 무엇 |
|---|---|---|
| `/reserve` | 손님 | 케이크·디저트 예약 (메뉴 고르기 → 날짜 → 시간 → 이름·번호) |
| `/` (테이블 QR → `/?t=3`) | 손님 | 메뉴판 → 옵션(온도·샷·사이즈) → 주문·결제 → **제조 완료 알림** · 후기 · 예약 주문 · 포인트 조회 |
| `/kds` | 카운터·제조 태블릿 | 새 주문 소리 알림 · 결제 확인 · 제조 시작 · **제조 완료(손님 폰에 알림)** · 픽업 완료 |
| `/staff` | 직원 | 개인 PIN 으로 출근/퇴근 · 오픈/마감 체크리스트 |
| `/admin` | 사장님 (비밀번호) | 아래 전부 |

### 사장님 화면 (/admin)
- 📊 **매출 분석** — 오늘/어제/이번 달, 일별·월별, 인기 메뉴, 시간대별, 요일별 · 재고 부족·유통기한·품절·미결제 알림
- 🧾 주문 내역 (날짜별, 취소)
- ☕ **메뉴 · 품절** — 메뉴/가격/옵션 등록, 품절 스위치. **자동 품절**: 디저트는 남은 개수 0, 음료는 레시피 재료 부족 시
- 🧈 **재료 · 재고** — 재료 등록, 입고(수량·유통기한·금액), 재고 조사로 수량 고치기, 유통기한 임박/지남 표시, 유통기한 빠른 것부터 자동 차감
- 🧮 **레시피 원가** — 1잔/1개당 재료 양 → 제조원가·원가율·마진 (재료 단가는 입고 금액으로 자동)
- 🥐 **생산일지** — 오늘 구운 개수·폐기 기록 → 판매량은 주문에서 자동, 폐기율
- 🚚 **발주 목록** — 최소 재고 이하/유통기한 지난 재료 자동 정리, 거래처에 보낼 문자 복사
- ⏰ 출퇴근 (월별 근무시간·예상 급여, 빠진 기록 수정) · 👩‍🍳 직원 (PIN·시급)
- ✅ 체크리스트 (오픈·마감 항목 관리, 누가 몇 시에 했는지)
- 🎁 고객 적립 (휴대폰 번호로 %적립, 사용 차감) · 🎂 예약 주문 · ⭐ 리뷰 · 🔮 판매 예측 (최근 8주 같은 요일 평균)
- 🔳 **테이블 QR 코드 인쇄** · ⚙️ 설정 (가게 이름·공지·적립률·테이블 수·비밀번호)

## 처음 설치 (서버, 한 번만)

```bash
cd /root && git clone https://github.com/pickgu2-create/sandbear-cafe.git
cd /root/sandbear-cafe
python3 app.py --set-owner-pw                  # 사장님 비밀번호 정하기
sudo cp sandbear.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now sandbear
```

주소 연결 (Caddy, HTTPS 필수 — 알림·결제가 https 에서만 됨): `/etc/caddy/Caddyfile` 에 추가 후 `sudo systemctl reload caddy`
```
sandbear.duckdns.org {
    reverse_proxy 127.0.0.1:8095
}
```
(duckdns 에서 `sandbear` 같은 새 주소를 만들어 서버 IP 로 연결)

그다음 사장님 화면에서: ① 직원 등록(PIN) ② 메뉴·가격 고치기 (예시 메뉴가 들어 있음) ③ 재료 등록 ④ 레시피 ⑤ 테이블 QR 인쇄

코드 업데이트 후: `cd /root/sandbear-cafe && git pull && sudo systemctl restart sandbear`

## 결제

- **지금(기본): 카운터 결제** — 손님은 폰으로 주문만, 결제는 카운터에서. 주문 화면에 '미결제'로 뜨고 직원이 '결제 확인'을 누름.
- **손님 폰에서 카드·간편결제(토스페이·카카오페이 등)** — [토스페이먼츠](https://www.tosspayments.com) 가맹(사업자등록증 필요, 심사 며칠) → 개발자센터에서 **결제위젯 연동 키** 2개를 받아
  `data/toss.env` 에
  ```
  TOSS_CLIENT_KEY=...
  TOSS_SECRET_KEY=...
  ```
  저장 → `sudo systemctl restart sandbear`. 처음엔 테스트 키로 해보고, 되면 라이브 키로 바꾸세요. 카드 결제 환불은 토스페이먼츠 관리자 화면에서.

## 포스기 연결에 대해

기존 포스기(OKPOS·토스플레이스·포스뱅크 등)와 **직접 연결은 포스 회사가 열어준 API·제휴가 있어야** 해서 지금은 안 돼요. 대신:
- 이 사이트의 `/kds` 를 카운터 태블릿에 띄우면 QR 주문이 소리와 함께 바로 떠요 (주문 접수·제조 완료 처리용 화면).
- 매장 카드 단말기 매출은 포스에, QR 주문 매출은 여기 남아요. 쓰는 포스 이름을 알려주시면 연동(또는 매출 엑셀 가져오기) 방법을 따로 알아볼게요.

## 손님 알림 방식

손님 폰의 주문 화면이 3초마다 상태를 확인하다가 직원이 '제조 완료'를 누르면 **소리 + 진동 + 큰 초록 화면 + (허용 시) 브라우저 알림**. 화면을 켜 둬야 확실해요 (아이폰은 잠금 화면 알림 제한 있음). 카카오 알림톡처럼 꺼진 폰에도 보내려면 알림톡 업체 계약이 필요해요.

## 보안
- 사장님 비밀번호·직원 PIN 은 암호화(scrypt)해서 저장 · 5번 틀리면 15분 잠금 · 사장님 로그인 12시간 유지
- 가격·품절·재고는 항상 서버에서 다시 계산 (손님 폰에서 금액 조작 불가) · 토스 결제는 서버가 금액 확인 후 승인
- 백업: `data/sandbear.db` 파일 하나만 복사해 두면 됨
